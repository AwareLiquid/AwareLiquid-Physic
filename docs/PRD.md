## 1. 背景与问题陈述

v0.1 验证了核心命题：**物理写进架构（硬约束）优于物理写进损失（软约束）**。辛积分 + 可分离哈密顿量在能量漂移上对无结构基线取得 3-6× 优势（轨道系统 100 步漂移 6.2 vs 37.8）。

但 v0.1 的 benchmark 同时暴露了三个结构性瓶颈：

| # | 瓶颈 | 证据 | 根因 |
|---|---|---|---|
| B1 | **context 信息量不足** | liquid_ham vs static_ham rollout MSE 仅 4.12 vs 4.41（5% 优势，远小于预期的适配收益） | `LiquidCore` 是"线性化 LTC"：时间常数 tau 是**静态可学习参数**而非输入依赖的液体时间常数；每个尺度是纯线性泄漏积分器，仅门控混合层有非线性 → 系统辨识（如推断弹簧刚度）能力受限 |
| B2 | **能量场无空间结构** | `V(q\|ctx)` 是逐点 MLP，无平移不变性、无交互结构；`phase_dim` 固定，无法处理网格/场/N-body | 缺失算子学习的核心归纳偏置（FNO 的傅里叶核积分提供全局感受野 + 分辨率不变性） |
| B3 | **数据效率低** | 仅用"前缀 → 未来"训练对；每轨迹一个训练样本 | 未利用时间演化半群性质（轨迹上任意时间对都是合法训练样本）；无预训练-微调范式 |

外部对标研究（已核实文献）给出的三条吸收路径：
- **真 LTC**（Hasani et al., AAAI 2021）+ **CfC 闭式解**（Nat. Mach. Intell. 2022）→ 修复 B1
- **FNO 傅里叶核积分**（Li et al., ICLR 2021）→ 修复 B2
- **半群 all2all 训练 + 预训练-微调**（Poseidon arXiv:2405.19101；Aurora Nature 2025）→ 修复 B3

同时保持与 Accelerated Understanding 的路线分野：AU 用"一次性 4D 输出"回避逐步预测的误差复合；本设计用**辛积分保能量**达到同一目标（长程稳定），并保留逐时间步输出带来的可解释性与守恒诊断能力。

## 2. 产品定位

**开源研究模型与基准**：神经算子能量场 + 真液体系统辨识 + 辛积分硬约束的三路线融合范例。

- 不是企业产品，不与 AU/Poseidon 竞争参数规模
- 是机制验证：证明"算子学习能量景观 + 硬约束动力学"组合的价值
- 保持 v0.1 的诚实定位：只在物理指标（rollout MSE、能量漂移、分辨率不变误差）上验证，不做语言建模、不做幻觉声明

## 3. 目标用户

1. 物理 ML 研究者：需要可复现的"算子 + 辛积分融合"实现与对照实验
2. 本仓库作者：学习载体与后续研究（LTC 研究、神经算子研究）的底座

## 4. 目标（P0 / P1 / P2）

### P0（本版本必须达成）

- **P0-1 真液体 context**：`LiquidCore` 升级为输入依赖液体时间常数（tau_sys 随输入调制），liquid vs static 的 rollout MSE 差距 ≥ 30%（v0.1 为 5%）
- **P0-2 算子能量场**：`V(q|ctx)` 支持 FNO 核积分层，可处理可变节点数（分辨率不变）的场/粒子集合输入；对 dim=1/2 低维系统行为与 v0.1 兼容
- **P0-3 守恒不退化**：新能量场 + 新 context 下，100 步能量漂移 ≤ v0.1 基线（守恒是架构性质，指标用于防退化验证）
- **P0-4 兼容性**：v0.1 全部 13 个测试保持通过；新增测试 ≥ 20 个

### P1（重要）

- **P1-1 半群 all2all 训练**：轨迹内任意时间对 (t_i, t_j) 作为训练样本；达到同等 rollout MSE 所需训练样本数 ≤ v0.1 的 1/5
- **P1-2 预训练-微调**：`physics_ops` 生成一族系统（弹簧族、轨道族、N-body、2D 场）预训练 → few-shot（≤ 20 样本）微调到新系统；目标：20 样本微调 ≈ FNO 用 1024 样本的精度（对标 Poseidon 样本效率）
- **P1-3 分辨率不变性**：64² 网格训练 → 256² 推理（零样本超分），相对误差 ≤ 训练分辨率的 2×

### P2（可选/后续）

- P2-1 N-body 与接触碰撞（physics_ops 已有引擎：pairwise_gravity、resolve_sphere_collisions）
- P2-2 非可分哈密顿量（速度依赖力 / 磁项）
- P2-3 概率化预测（扩散式 ensemble，对标 GenCast 路线）
- P2-4 时间条件化（连续时间评估，对标 Poseidon 的 time-conditioned LayerNorm）

## 5. 非目标（明确不做）

- ❌ 不做 1T 参数级企业模型（AU 赛道）
- ❌ 不做语言/多模态任务
- ❌ 不声称替代超算数值仿真（保持"CPU 可跑的机制验证"定位）
- ❌ 不引入 Transformers 自注意力为核心机制（FNO 的谱域算子已提供全局交互；如实验需要，仅作消融对照）

## 8. 风险与开放问题

| 风险 | 等级 | 缓解 |
|---|---|---|
| autograd-of-FNO 梯度成本：每 Verlet 步 2 次对 q 的梯度 + 谱层反传，长 rollout 变慢 | 中 | M2 先做梯度成本 benchmark；必要时在谱层用解析谱梯度 + 混合精度 |
| FNO 的周期性假设与真实物理域（非周期）冲突 | 中 | 标准做法：输入 padding 或分组傅里叶（grouped FNO）；在架构文档中定案 |
| 输入依赖 tau 破坏 `pscan_constant_A` 的假设（A 随时间变） | 低 | 仓库 `pscan` 已支持逐时间步 A；M1 改用通用 pscan，测试对齐 `pscan_sequential` |
| 真 LTC 的 ODE 稳定性（原版 LTC 需专用求解器） | 低 | 用 CfC 式闭式离散化而非数值 ODE 求解器，保持扫描式训练 |
| context 条件化方式选择（concat vs FiLM vs hypernetwork）影响表达力 | 中 | M2 做消融实验（三选一定案进 ADR） |

## 9. 实施进展记录

| 里程碑 | 状态 | 内容与实测 |
|---|---|---|
| **M1: 真液体 context** | ✅ 已实现 + 已训练 | 输入依赖 tau + 通用 pscan。liquid vs static rollout MSE 差距：**v0.1 的 5% → 11%（500 步）→ 21%（2000 步，最佳记录，远程 A100 复现一致）**；liquid 全指标反超 gru_seq。lr decay 无益；**FiLM 条件化消融（负结果）**：短窗口训练下 FiLM 比 concat 更易过拟合 context（train_loss 1.7e-2 但 rollout 发散 9x），M1 保留 concat（ADR-4 修订） |
| **M2: 算子能量场** | ✅ 已实现 + 已训练 | FNO 势能 + FiLM。非均匀介质任务：liquid 增益 seed 依赖（漂移优 40% 或 MSE -16.5%，不稳健）。分辨率不变性：均匀模式 1.3x 达标；非均匀 3.0x |
| **M3: 数据效率与泛化** | ✅ 已实现 + 已训练 | few-shot 优势：**1.26x → 1.68x → 2.00x → 2.43x**（单调至 512 条/速度，1024 条后饱和 ~2.4x，目标 3x） |

**平台期结论（诚实）**：三个方向均到达当前架构/任务配置的平台期——M1 21%、M2 增益不稳健、M3 ~2.4x。继续加大预算不再增益；突破需架构/任务层面的变化（M3 预训练任务多样性、M2 多 seed 评估 + 更强模型、M1 长窗口训练配合 FiLM）。负结果与正结果同样有价值：FiLM 层序（ADR-7）、FiLM 与训练窗口的适配性（ADR-4 修订）都是从失败中得到的硬结论。

测试：**26/26 通过**（本地 + 远程 A100 均验证）。

待办：P2 扩展（N-body/非可分/概率化）为后续版本。

## 10. A100 训练结果（两波并行，GPU 99% 利用率）

| 任务 | 最终结果 | 结论 |
|---|---|---|
| **非可分（磁场，隐式中点）** | rollout_mse **1.40e-4**，漂移 5.97e-2，train_loss 4.7e-9 | ✅ 硬约束路线在非可分系统上工作极好 |
| **时间条件化（受迫振子）** | rollout_mse **4.26e-6** | ✅ 时间条件化学透时变动力学 |
| **M3 预训练微调** | few-shot **2.80x**（1024 条/速度 + 5000 预训练步） | ✅ 新纪录，逼近 3x 目标 |
| 2D 谱算子 | liquid 1.09e-2 vs **static 1.78e-3**；分辨率 16→32 零样本 1.89e-3 | static FNO 在齐次周期膜上更强（无需系统辨识）；分辨率不变优秀 |
| M2 非均匀 1D（5 seeds） | liquid 1.93e-2±4.3e-4 vs static 1.75e-2 | 接近打平，static 略优 |
| N-body（5 seeds） | liquid 14.62 vs static 14.87 | liquid 略优 1.7%（混沌系统） |
| 概率化 | ensemble MSE 2.40（1000 步时 1.36 更优），spread 4.8e-2 | 工作正常，长训练无益 |
| M1（GPU 数据） | liquid 7.57 vs static 3.21 | ⚠️ **CUDA generator 数据分布与 CPU 不同**——M1 的 21% 最佳记录是 CPU 数据；GPU/CPU 数据不可比，device 内可复现 |

**核心结论**：硬约束架构（守恒进架构）在全部六类物理系统上验证成功——非可分/时间条件化拿到 1e-4~1e-6 级误差；liquid 系统辨识的增益集中在"有隐藏参数族"的任务（M1 弹簧 21%、M3 few-shot 2.8x），对"齐次系统无需辨识"的任务（2D 膜、1D 波）static 已足够——与 PRD 假设一致。

## 13. 第五波：半群训练突破（M1 P0-1 目标大幅超额达标）

**发现：半群训练（任意起点）彻底改变 M1 结论**——`benchmarks/m1_semigroup_eval.py`：

| 配置 | liquid vs static | 优势 |
|---|---|---|
| 固定窗口 + CPU 数据（原记录） | 2.857 vs 3.610 | 21% |
| 固定窗口 + GPU 数据（"退化谜团"） | 7.57 vs 3.21 | 无优势（过拟合：train_loss 1.2e-2 但 rollout 发散） |
| **半群训练 + CPU 数据** | **1.418 vs 3.684** | **61.5%** ✅✅ |
| **半群训练 + GPU 数据** | **0.586 vs 3.100** | **81.1%** ✅✅ |

**结论**：① 半群训练（任意起点，train_semigroup）把 M1 的 liquid 优势从 21% 提升到 **61.5%（CPU）/ 81.1%（GPU）**——**P0-1 的 30% 目标大幅超额达标**；② "GPU 数据退化"不是数据问题，而是固定窗口训练的脆弱性（过拟合固定窗口），半群训练的正则效应（轨迹上任意时间对）在 GPU 数据下反而更强。**半群训练是 M1 的解药**，与 M2/M3 的经验一致——半群训练应成为所有任务的默认。

## 14. 第六波：半群突破稳健性验证（7 配置全部超额达标）
